{# Shared challenge rule-row editor — used by both challenges.html (creation time, one editor per editable preset card) and challenge_detail.html (post-creation editing via POST /challenges/{id}/rules). Consolidated from two independently-coded implementations (challenges.html's addRule/ collectRules and challenge_detail.html's addEditRow/saveRules) during /plan-eng-review — see the "Custom Challenge Templates" design doc, Issue 3. Module boundary (locked in design review, outside voice Issue 6): this module owns row markup, the Tick/Photo kind toggle, and rule-collection logic only. It never makes a network call — each call site keeps owning its own submit lifecycle (challenges.html bundles the collected rules into a caller's POST /challenges body; challenge_detail.html's editor owns its own submit button and POST /challenges/{id}/rules call). Invariant (outside voice Issue 7): rows with kind == "workout" never render the kind toggle or a remove control, in any container this module renders into — preserves the pre-existing special-casing for 75 Hard/75 Medium's auto-ticking workout rule across both editors. #}
